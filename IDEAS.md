# HyperSpell — Idea Backlog

A parking lot for ideas we're **not** ready to build yet, but might want later.
Not a commitment or a plan — just so good ideas don't get lost. Move an item into a
real plan/PR when its time comes; delete it if we decide against it.

Format per idea: a short title, the gist, and (optionally) why it's parked / what it'd touch.

---

## Wizard classes

Different **classes of wizard**, where each class casts spells **of its own school
better** — more damage / lower cooldown / bigger effect for spells that match the
class, maybe a small penalty or no bonus for off-class spells.

- Ties naturally into the existing 7-school system (FIRE / ICE / ZAP / AIR / EARTH /
  VOID / LIFE) and the tome/fusion machinery.
- Open questions: pick class in the lobby vs. randomly assigned? One passive bonus or
  a signature spell too? How does it interact with fusions (hybrid spells span schools)?
- Would touch: player setup/lobby, spell cast math, HUD (show class), maybe art.
