pass for HYPERSPELL

Every visual in the game is drawn live in code — no image files. This is the same code path the game runs, rebuilt with ink outlines, cloth-fold shading, rim light, runes and a parchment-warm palette. Everything below is animating, and everything stays recolorable per player.

The thesis

A duel, alive

Three wizards at full, dented, and near-death — the hat still is the health bar — over the new backdrop, with a grimoire and the Mega Hat falling. Left to right: proud, knocked askew, smoldering.

Champions

Named wizards, their own selves

Some players don't get the house robe. Detected by name in the shared draw path, so they look like themselves on every screen — yours, the LAN clients', the killcam, the victory screen.

Backgrounds

One backdrop per world

The flat wash is gone. Each arena now reads its biome — parallax silhouette ranges for depth, a moon or ringed planet, aurora, drifting embers — all derived from the map's own palette.

Terrain

Stone that lives

Platforms were flat single-colour slabs. Now they're carved stone with a cracked, speckled face, an ink silhouette, and an animated crust that reads the biome — grass sways, snow sparkles, embers flicker, crystal pulses. A wizard stands on each for scale.

Random environmental effects

The weather, rolled once in five rounds

These fire at random, so you rarely see them back-to-back. Here they all are, live — each over a little scene so you can read it in play.

This preview inlines a copy of the shipping toolkit. In the repo it lives at js/artkit.js, and the game's draw* functions are now thin adapters that call into it — one source of truth. To extend the pass to the rest of the board (bosses, hazards, per-spell FX, HUD), add a drawStory* builder and point the adapter at it.

An artist onboarding here works in js/artkit.js: author or tune a drawStory* function, view it in this gallery, ship it. No pipeline, no export step.
